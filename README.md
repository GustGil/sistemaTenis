O "Nome sistema" surge da necessidade de uma especie de blog especializado em tenis esportivos, sendo uma ferramenta de busca, comparação e ensinamento sobre questões do calçados esportivos. Segue informações interessantes sobre o sistema presente nesse repositorio

**Ideia inicial do sistema:**
 
- base de dados de tenis esportivos de diversas modalidades
- demonstração de dados sobre solado, amortecimento, encaixe, responsividade e cabedal do calçado
- demonstração de tecnologias presente em calçados
- listagem por filtro
- sistema de pontuação realizado por LLM, dando uma visão concreta sobre as tecnologias presentes no tenis(exemplo: amortecimento:9/10, solado 9,2/10...)
- Guia de cuidados com o tenis, lavagem e como guardar



O inicio do projeto já surge com o grande problema da ausência de uma base de dados grandes e com dados suficientemente detalhados para o cumprimento das funcionalidades, sendo necessario fazer uma coleta de dados grande, com elementos de crawler, scraping e coletores.
